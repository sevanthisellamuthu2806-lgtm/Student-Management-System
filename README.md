# Student Management System

A console-based Student Management System developed using C++ and file handling.

## Features

- Add Student
- Display Student Records
- Update Student Information
- Delete Student Records
- Persistent data storage using file handling
- Menu-driven interface

## Student Details

The system manages:

- Student ID
- Student Name
- Age
- Course

## Technologies Used

- C++
- File Handling
- Structures
- Functions
- Console Programming

## How to Run

Compile and run `StudentManagementSystem.cpp` using any C++ compiler.
